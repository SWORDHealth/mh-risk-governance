# mh-risk-governance
Data and evaluation artifacts for the paper arXiv:2607.22692.

## Contents

- `single_prompt_final_eval_paper/` — external single-prompt evaluations on
  NVIDIA Aegis 2.0 and CRADLE Bench: dataset revisions, splits, label mappings,
  exact test sets, per-row predictions, and confusion matrices (see its README).
- `safety_layer_annotations/` — 662 synthetic counselling conversations
  annotated turn-by-turn for risk by licensed clinicians, with the prompts used
  to build the synthetic patient profiles (see its README).
